01 Five modules, one window

Each tab answers a different question you would otherwise spend an afternoon on. They share one rule: what is wrong, why it hurts, what to press.

1
Checkup — Scene & Code
Static analysis of the open scene, your project settings and your scripts. Instant, no Play Mode. 34 scene and project rules plus 15 code rules: realtime shadow-casting lights, missing scripts, realtime GI, a disabled SRP Batcher, UI raycast spam, Read/Write enabled meshes and textures, Layout Groups rebuilding every frame, animation culling, physics settings. Each finding gets Select, Fix and Learn more.
Health Score 0–100 Select the guilty objects One-click Fix with Undo Code scan with confidence rating
2
Project Assets
What has accumulated on disk, whether or not you have ever made a build. Dead Asset Stripper finds files nothing reaches from a build scene, a Resources folder or an Addressables entry — dry run first, quarantine second, never a delete. Duplicates finds byte-identical files and materials that differ only by name. Import Settings finds meshes and textures keeping a second copy in memory, Humanoid rigs nothing retargets, and animation clips paying for scale curves.
Dry run before anything moves Quarantine, not delete Backup .unitypackage on every move Byte-identical and equivalent-material duplicates
3
Build X-Ray
After any build: total size, the twenty heaviest assets, a breakdown by type and by folder, an interactive treemap, and a duplicate finder. Fixes are one click and show you the saving before you apply them — "compress this texture: −41 MB". Includes a mesh import view for rig and blend shape data you are shipping but never use.
Interactive treemap Top-20 heaviest assets Duplicate finder Estimated saving before you apply
4
Performance Hunter
Press Start, play your game for twenty seconds, press Stop. You get a list like "PlayerController.Update() allocates 2.1 KB every frame — cause: string concatenation" with a double click that opens the file on the line. Every caught pattern comes with the fix from a rule base: string concat → StringBuilder, LINQ in Update → for loop, GetComponent in Update → cache it in Awake.

02 What WhySlow is not

A tool that oversells itself wastes your afternoon. So, plainly:

Not a Profiler replacement

It is first aid. When you need frame-by-frame timeline detail, you still open the Unity Profiler — WhySlow gets you to the point where you know what to look at.

Not a magic optimiser

It never touches your project until you press Fix, and it only offers a Fix where the change is safe and reversible. Design decisions stay yours.

Not in your build

The assembly is Editor-platform only. Zero bytes reach your player build — no runtime component, no define, no stray Resources folder.

Not a black box

No DLLs. Full C# source, one asmdef, and a demo scene built specifically to fail the checks so you can see what the tool reports before you point it at your own project.

FAQ

03 Questions people ask first

▼ Will it break my project?

Nothing changes until you press Fix. Scene and project edits go through Unity's Undo system. Importer changes are backed up before they are written and can be restored per asset or per operation, so a bulk texture compression is one click to undo as well.

▼ Which Unity versions?

Unity 2021.3 LTS and newer, verified on Unity 6. Built-in and URP, on Windows, macOS and Linux editors.

▼ Does it need an internet connection?

No. There is no telemetry and no network code at all. Nothing about your project leaves your machine, which also means it works behind a corporate firewall.

▼ Do I have to configure anything first?

No. Open Window → WhySlow and press the button. Settings exist, but you should never need them to get your first answer.

▼ I'm not a performance person. Will I understand it?

That is exactly who it is written for. No jargon in the headlines — the words SetPass, GC.Alloc and mipmap only appear inside "Learn more", next to a link to the relevant Unity documentation.

▼ Something is wrong or missing. Now what?

Write to sburdenko@gmail.com. I read everything and answer within a day. If a check reports something wrong for your project, send the Unity version and the case — a wrong finding is a bug and gets fixed like one.
