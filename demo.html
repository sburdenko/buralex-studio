01 Where to start

Five tabs, each answering a different question. If you only try one thing, press Fix all safe issues on the Checkup tab and watch the score climb.

Checkup

  • Switch the Profile between Mobile, Desktop and WebGL — the rules that only apply to a target appear and disappear.
  • Learn more on any finding opens the full "What to do" text that ships with the tool.
  • Optimization Wizard walks the findings one at a time and reports the score change at the end.
  • The Code sub-tab scans scripts without Play Mode.

The other four

  • Project Assets — scan for dead files, duplicates and wasteful import settings, then quarantine or fix them.
  • Build X-Ray — press "Make a build", then click the treemap tiles and compress an asset.
  • Performance Hunter — press Start Hunt, wait a few seconds, press Stop. The verdict and the call sites follow.
  • Compile Time — press Analyze to price every assembly by what it drags into a rebuild.

02 What is real and what is not

A demo that quietly exaggerates is worth nothing, so here is the line.

Real

  • The tab structure, the sub-views and every button label.
  • Finding titles, the one-line "why this hurts" and the full "What to do" text — verbatim from the tool.
  • The Health Score formula: 100, minus 12 per critical and 4 per warning.
  • The palette, taken from the same source file the editor window uses.
  • Which fixes are safe to batch, and which are deliberately kept out of Fix All.

Not real

  • The project. There is no scene, no build and no Play Mode behind this page.
  • The numbers. Asset sizes, timings and allocation rates are plausible, not measured.
  • Select, Show in Scene and Open source line — in Unity they act on your project; here they explain themselves instead.
  • The allocation graph, generated in the browser rather than read from the profiler.
  • The Options menu, which the real window carries next to the tabs — Share report, Unity's default look, and the ignore lists — is left out here because none of it would do anything.
